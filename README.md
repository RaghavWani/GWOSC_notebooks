# GWOSC_notebooks

This repository contains Google Colab notebooks used in the Gravitational Waves Open Science Center's workshops held in 2023 and 2024.

The content of each notebook matches what is freely available on the [GWOSC Courses webpage](https://gw-odw.thinkific.com/), with additional solved problems included at the end.
These courses provided an excellent introduction to working with data from gravitational wave detectors through insightful lectures and hands-on programming exercises.
I learned various tools for gravitational wave data analysis, many of which can be applied to other fields.
